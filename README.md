## 📌 Deskripsi

**MANZAX GENERATOR** adalah tools premium untuk menghasilkan akun **Free Fire (FF)** dengan kecepatan super ekstrim.  
Dirancang dengan arsitektur multi-threading tingkat tinggi, tools ini mampu menghasilkan ratusan akun dalam hitungan menit.

---

## ✨ Fitur Unggulan

| Fitur | Keterangan |
| :--- | :--- |
| 🚀 **Kecepatan Ekstrim** | Mendukung hingga **3000 thread** paralel. |
| 🌐 **Multi Region** | Support **ME, IND, ID, VN, TH, BD, PK, TW, CIS, SAC, BR (Ghost)**. |
| 🎯 **Sistem Rarity** | Otomatis mendeteksi ID Cantik (Rare, Epic, Legendary, Divine). |
| 💕 **Sistem Couple** | Mendeteksi pasangan ID Berurutan / Mirror. |
| 📂 **Sortir Otomatis** | Hasil akun otomatis masuk folder `MANZAX_LEGACY` & `MANZAX_SORTED`. |
| 🔒 **Anti WAF** | Bypass Cloudflare/Garena dengan sistem IP dinamis. |
| 📨 **Notifikasi Telegram** | Kirim notifikasi otomatis ke Telegram saat dapat akun Rare/Couple. |
| 🗝️ **Sistem Lisensi** | Menggunakan Support Key (diberikan saat pembelian). |

## 📦 Persyaratan Sistem

Sebelum menjalankan, pastikan perangkat Anda memenuhi syarat berikut:

- **Sistem Operasi:** Android (Termux / Acode) atau PC (Windows/Linux/macOS).
- **Python:** Versi **3.12** atau lebih tinggi.
- **Koneksi Internet:** Stabil (untuk generate akun).

---

## 🔧 Langkah Instalasi Dependensi

Buka terminal Anda, lalu jalankan perintah berikut untuk menginstall library yang dibutuhkan:

```bash
pip install pycryptodome requests colorama
```

⚠️ Jika menggunakan Termux, mungkin perlu install python dan pip terlebih dahulu:

```bash
pkg install python
```

---

🚀 Cara Menjalankan

1. Pastikan file AegisCrypt_PROTECTED.py (atau brand lainnya) sudah berada di direktori kerja Anda.
2. Jalankan perintah:
   ```bash
   python AegisCrypt_PROTECTED.py
   ```
3. Masukkan Support Key yang telah diberikan saat pembelian.
4. Pilih Region yang diinginkan.
5. Atur Jumlah akun dan Jumlah Thread (disarankan 500–2000 sesuai spesifikasi HP/PC).
6. Tunggu proses hingga selesai.
